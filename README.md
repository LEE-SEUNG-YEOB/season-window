# season-window

국립수목원 식물계절 관측자료 17년치로 개화·단풍 시기가 **해마다 얼마나 흔들리는지** 분석하고,
지자체 축제 담당자가 축제 기간과 수종을 정할 때 쓰는 도구를 만든다.

머신러닝 팀 프로젝트(3인) · 산림청 산림공공데이터 활용사례 공모(자체 활용형) 출품

## 문제

꽃 축제는 몇 달 전에 일정을 정하지만 개화 시기는 해마다 달라진다.
2025년 광양매화축제는 개막 초 개화율이 10% 수준이었고 방문객이 전년보다 11만 8,000명 줄었다.
지자체는 축제 기간을 늘려 대응하지만, 며칠을 늘려야 충분한지에 대한 근거는 없다.

## 차별점

| 기존                                       | 답하는 질문                                                  |
| ------------------------------------------ | ------------------------------------------------------------ |
| 서울대·국립수목원 논문(2026)               | 17년 동안 평균적으로 어느 방향으로 변했는가                  |
| 국립수목원 단풍절정일 조회, 민간 개화 예보 | 올해 언제인가                                                |
| **이 프로젝트**                            | 해마다 얼마나 달라지는가, 그러면 기간을 어떻게 잡아야 하는가 |

예측은 기본 기능으로 두고, 변동 폭을 이용한 축제 기간 설계와 수종 추천을 중심에 둔다.

사용 범위

- 관측 위치: 수목원 전시원 10곳(26,460줄, 정제 후 26,408줄). 산지 위치는 평지 기상 관측소로 설명할 수 없어 예측 모델에서 제외
- 추천 대상: 꽃과 단풍을 보는 16종
  - 봄꽃 11종: 왕벚나무, 진달래, 산수유, 미선나무, 백목련, 개나리, 생강나무, 아까시나무, 철쭉, 산철쭉, 마가목
  - 단풍 5종: 단풍나무, 당단풍나무, 은행나무, 신갈나무, 졸참나무
- 침엽수 4종(소나무, 잣나무, 주목, 구상나무)은 비교용

## 주요 결과

- 개화일은 해마다 6일 안팎 흔들리고, 그 절반은 전국이 함께 움직이는 연도 효과다. 지역 간 변동 폭 차이는 확인되지 않았다.
- 늦게 피는 종일수록 개화 시기가 안정적이다 (종별 4.9~7.7일, 평균 개화일과의 상관 -0.85).
- 일찍 피는 종은 변동 폭이 크지만 더 오래 피어서, 날짜를 고정한 축제에는 오히려 잘 맞는다.
- 2월 말까지 알 수 있는 기상으로는 개화일 예측이 과거 평균보다 뚜렷이 나아지지 않았다(랜덤포레스트 포함). 과거 평균에 최근 5년 경향을 더한 방법을 채택했고, 3월 기온은 가정 입력으로 받는다.

자세한 내용은 [docs/key_findings.md](docs/key_findings.md), 차트는 `reports/figures/`, 정제 기준은 [docs/cleaning_rules.md](docs/cleaning_rules.md), 모델 검증은 [modeling/README.md](modeling/README.md).

## 기능

| 기능                  | 입력                        | 출력                                                                     |
| --------------------- | --------------------------- | ------------------------------------------------------------------------ |
| 1. 개화일·단풍일 예측 | 지역, 종, 현상, 연도        | 예상 날짜와 오차 범위, 17년 평균과의 차이                                |
| 2. 축제 기간 설계     | 지역, 종, 축제 시작일, 일수 | 꽃 시기와 겹칠 확률, 같은 일수로 확률이 가장 높은 기간, 일수별 확률 변화 |
| 3. 수종 추천          | 지역, 원하는 시기           | 종 순위, 적합도(지난 해 중 꽃 시기가 겹친 해의 비율), 안정성 점수        |

- 예측 모델: 과거 평균(기준), 과거 평균 + 최근 5년 편차, 2월 기온 직선 모델, 랜덤포레스트를 연도 단위 검증(한 해씩 빼기, 앞으로 가는 검증, 최근 4년 떼어 두기)으로 비교했다. 채택 규칙은 결과를 보기 전에 정했다
- 기능 2·3은 봄꽃(개화)만 지원한다. 단풍 시기를 어느 단계로 볼지 정해지지 않았다
- 화면: Streamlit. 지도에서 전시원 10곳 중 하나를 선택하고, 세 기능이 같은 선택을 공유

## 실행

`data/` 아래에 원본과 정제본을 넣은 뒤(받는 방법은 `data/README.md`) 저장소 맨 위에서 차례로 실행한다.

```bash
# A: 정제와 분석 (pandas, numpy, matplotlib, openpyxl)
python analysis/01_clean_phenology.py   # 01~06을 번호 순서대로
# B: 변수와 모델 (scipy, scikit-learn 추가)
python modeling/weather.py              # 순서는 modeling/README.md 2절
# C: 화면
streamlit run service/app.py
```

## 데이터 이용 조건

원본 자료에 상업적 이용 제한 조건이 있어 학술·연구 목적으로만 사용한다.
원본과 정제본은 저장소에 올리지 않으며, 차트와 집계 결과만 공개한다. 받는 방법은 `data/README.md` 참고.

## 한계

| 한계                   | 구체적으로                                                       | 대응                                                   |
| ---------------------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| 지역이 10곳뿐          | 수목원 전시원 10곳의 기록만 사용, 산지 관측 지점은 제외          | 수목원이 없는 시군구는 가까운 수목원 값을 참고용으로만 쓴다 |
| 조합마다 기록 연수가 다름 | 봄꽃 110개 조합 중 8년 이상 기록된 조합: 예측 91개, 추천 87개    | 8년 미만이면 계산하지 않고 화면에 이유를 보여 준다     |
| 관측 간격이 김         | 다음 단계가 기록되기까지 중앙값 7일, 7일·14일·21일에 몰림        | 2~3일 차이는 해석하지 않고 날짜 대신 범위로 제시한다   |
| 기상 관측소와의 거리   | 연결한 관측소까지 2.5~23.2km, 나무의 해발고도 정보 없음          | 기상은 분석에만 쓰고, 채택한 예측은 지난 기록만 쓴다   |
| 단풍은 예측만 지원     | 단풍 시기 기준 미정, 8년 이상 기록된 조합이 50개 중 19개         | 기능 2·3은 봄꽃만 지원한다                             |
| 예측 정확도            | 앞으로 가는 검증 평균 오차 4.75일 (과거 평균만 쓰면 5.45일)      | 기존 예보보다 정확하다고 주장하지 않는다               |

그림은 소개 페이지 `site/data.html`의 한계 절에 있다.
