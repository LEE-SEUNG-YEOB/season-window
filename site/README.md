# 소개 페이지 (공모전 제출용)

공모전 심사위원이 볼 소개 사이트입니다. 집계 결과만 들어 있고, 원자료와 정제본의 해별 기록은 들어 있지 않습니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 처음 화면. 고정된 축제 기간(4월 3일~11일)과 해마다 움직이는 왕벚나무 개화를 2010~2025년 순서로 보여 줍니다 |
| `findings.html` | 알아낸 것: 연도 효과, 종별 흔들림, 고정 날짜 적중률(검증 전환), 먼저 핀 꽃의 단서, 장기 추세 |
| `tool.html` | 만든 것: 세 기능의 예시 화면(국립수목원·왕벚나무 실제 계산 결과), 예측 방법 검증표 |
| `data.html` | 데이터와 방법: 배경, 봄꽃 11종 달력, 쓴 데이터, 처리 순서, 개선점 6가지, 한계, 참고 기사 |
| `assets/site.css`, `assets/site.js` | 네 페이지가 함께 쓰는 스타일과 동작 |

## 배포

```
npx vercel deploy site --prod
```

또는 Vercel 프로젝트 설정에서 Root Directory를 `site`로 지정합니다. 빌드 과정은 없습니다.

## 움직임

jakub.kr의 better-motion 기준을 따릅니다. 처음 불러올 때와 화면에 처음 들어올 때만 한 번 등장(덩어리 100ms, 제목 단어 80ms 간격, opacity + blur 4px + 12px, 300ms)하고, 그 뒤로는 사용자가 누를 때만 움직입니다. 버튼은 누르면 0.96으로 줄고, 탭과 전환 버튼의 표시가 두 칸 사이를 이동합니다. 기기에서 동작 줄이기를 켜면 움직임과 흐림은 빠지고 opacity만 남습니다.

## 숫자를 바꿀 때

페이지에 들어간 값은 `reports/tables`의 집계 결과와 `modeling`의 계산 결과에서 옮겨 각 HTML 안에 직접 넣은 것입니다. 분석을 다시 돌려 값이 바뀌면 해당 페이지의 값도 고쳐야 합니다.

`data.html`의 기사 수치(광양매화축제, 서울 벚꽃)는 계획서에서 옮긴 것으로, 제출 전에 원문 기사와 한 번 더 대조해야 합니다.
