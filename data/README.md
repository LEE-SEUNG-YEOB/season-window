# data/ — 저장소에 올라가지 않는 폴더

이 폴더의 데이터 파일은 `.gitignore`로 전부 제외된다(폴더 뼈대와 이 문서만 올라감).
원본 자료에 상업적 이용 제한 조건이 있고 재배포 가능 여부를 확인하지 못했기 때문이다.
팀원끼리는 git이 아닌 다른 경로(메신저, 공유 드라이브 등)로 주고받는다.

| 폴더 | 넣는 것 | 비고 |
|---|---|---|
| `raw/phenology/` | 식물계절 장기관측 DB xlsx 20개 (종별 1개) | 받은 그대로, 파일 이름 변경 금지, 수정 금지 |
| `raw/weather/` | 기상청 ASOS 일자료 csv 2개 (cp949) | 받은 그대로, 수정 금지 |
| `interim/` | 임시 정제본 (17일 오전 B, C 전달용) | 스크립트가 생성 |
| `processed/` | 최종 정제본 (식물계절, 기상) | 스크립트가 생성 |

`raw/`는 읽기 전용으로 취급한다. 모든 가공 결과는 `interim/`이나 `processed/`에 새 파일로 만든다.
