# 프로젝트 기준 문서 (최우선 참고)

작업을 시작하거나 판단이 필요할 때 가장 먼저 보는 요약이다.
출처는 네 가지: 프로젝트 계획서(2026-11-16), 수업 과제 안내 슬라이드, 공모전 공고, 깃허브 저장소.
원문과 이 요약이 다르면 원문이 우선한다.

## 1. 프로젝트 계획서 요약

- 주제: 국립수목원 식물계절 관측자료 17년치(2009~2025)로 개화·단풍 시기의 **해마다 변동 폭**을
  종·지역별로 밝히고, 지자체 축제 담당자가 축제 기간을 정할 때 쓰는 도구를 만든다.
- 구현: Python, Streamlit, 지도. 기능 3개
  1. 개화일·단풍일 예측 (랜덤포레스트/부스팅, 종을 변수로 넣은 모델 하나, 최근 3~4년 검증)
  2. 축제 기간 설계 (입력 기간이 꽃 시기와 겹칠 확률, 꽃 시기 = 개화시작~낙화)
  3. 수종 추천 (적합도 = 17년 중 그 시기에 나타난 해의 비율, 안정성 = 표준편차를 0~100점 환산)
- 차별점: 날짜 예측과 장기 추세는 기존 논문·서비스가 이미 다룸. 우리는 변동 폭, 축제 기간 설계, 수종 추천.
- 사용 범위
  - 관측 위치: 세부관측이 "전시원"인 10곳, 약 26,460줄. 산지 위치는 예측 모델에서 제외
    (날짜만 쓰는 변동 폭 비교에는 시간이 남으면 활용)
  - 봄꽃 11종: 왕벚나무, 진달래, 산수유, 미선나무, 백목련, 개나리, 생강나무, 아까시나무, 철쭉, 산철쭉, 마가목
  - 단풍 5종: 단풍나무, 당단풍나무, 은행나무, 신갈나무, 졸참나무
  - 침엽수 4종(소나무, 잣나무, 주목, 구상나무)은 비교용
- 단계 이름
  - 꽃: 꽃눈파열, 개화시작, 개화50%이상, 낙화90~100%, 비산시작, 비산종료
  - 잎: 잎눈파열, 개엽시작, 개엽완료, 단풍시작20~30%, 단풍50%이상, 단풍90~100%, 낙엽90~100%
  - 열매: 열매생성, 열매성숙완료
- 정제 전 임시 값(왕벚나무): 개화시작일 표준편차 수목원별 3.7~10.1일, 개화시작~낙화 중앙값 14일
- 아직 확인하지 못한 것
  - 이 자료가 공모전의 "산림공공데이터"로 인정되는지 (C가 주최 측에 문의)
  - 20종 전체에서도 종·지역 간 변동 폭 차이가 뚜렷한지 (A가 정제 직후 가장 먼저 계산)

## 2. 수업 평가 기준 (6~7주차 기획과 13~14주차 구현이 합쳐짐)

- 발표: 그룹 평가, 최장 15분, 3개 이하의 서비스 시나리오로 시연
- 결과 보고에 들어갈 것: Project overview와 최종 결과물, Data Set 수급과 작업방식,
  구성원 R&R과 단계별 결과물, 보완 필요성, 대외 출품 일정 및 결과
- 제출물: 결과보고서, 매뉴얼, 소스 코드
- 배점
  - 창의성 및 기존 유사 서비스와의 차별화 30
  - Project 난이도 20
  - 결과물 구성 및 완성도 30 (기획 단계 기준으로는 결과물 활용 계획 30: 지자체 협의, 공모전 출품 등)
  - 내용 및 발표력 20 (진행 방법, R&R, 스케줄, 서비스 시나리오)
  - 기여도에 따라 최대 +30, -30
- 좋은 발표의 요건: Informative, Interesting, Interactive, In Time. 자료에는 Story, 간단 명료, 출처(Reference)
- 교수님 강조: "이 데이터로 무엇을 알아냈는가"가 가장 중요, 뻔한 결과는 감점

A 작업에 주는 의미: 정제 기준과 단계별 산출물을 그대로 "작업방식"과 "단계별 결과물"로 보고할 수 있게
기록한다. 차트에는 자료 출처를 적는다. 핵심 발견은 이야기 순서로 정리한다.
